# XHS To Feishu (小红书一键收藏入库)

![License](https://img.shields.io/badge/license-MIT-blue.svg)

一个专为内容创作者/媒介运营打造的 Chrome 浏览器插件。支持在小红书笔记页面点击按钮，将笔记极其详尽的图文内容、甚至包含无水印原图和无水印视频、封面、作者数据等，一键自动推送到你的 **飞书多维表格** 中。

## ✨ 核心特性

- **📸 媒体全自动解析**
  - 不管是图文笔记的高清无水印原图，还是视频笔记里的**无水印纯净视频**，扩展都会用前端逆向的接口精准解析。
  - 直接将媒体一键转存上传为飞书表格的「附件对象」。
- **📝 数据深度收割**
  - 除笔记链接外，自动提取文案（包含换行还原）、作者名字、乃至笔记内的各项结构化参数，无缝填入表格字段。
- **🔄 防重去重机制 (Upsert)**
  - 根据小红书笔记的唯一 `note_id` 自动判定表格中是否已存在该笔记，如果是，则更新其数据而非重复创建。
- **🛡️ 无感悬浮窗**
  - 直接在小红书的网页右下角注入一个极具设计感的红色“收藏”悬浮球，不仅可以使用插件弹窗，更可以点页面悬浮球做到沉浸式的体验。
- **🔒 纯本地请求**
  - 不走任何第三方后台接口爬去，直接从浏览器的全局运行时提取 Redux 数据结构，并直接与飞书 Open API 通信！所有的密钥均存储在 `chrome.storage.local`。

## 📦 安装指南

1. 克隆或下载本仓库代码到本地。
2. 打开 Chrome (或 Edge) 浏览器，进入扩展管理页面 `chrome://extensions/`。
3. 开启右上角的 **“开发者模式”**。
4. 点击 **“加载已解压的扩展程序”**，选择本项目的 `chrome-extension` 目录。

*(如果目录没有拆分出 chrome-extension，则选择根目录即可)*

## 💡 首次配置与使用

1. **飞书授权：**
   - 准备一个你想要填写的飞书多维表格，创建一个飞书企业自建应用 (`App ID` & `App Secret`)。
   - 确保你的飞书应用具备 `bitable:app` 相关的读写权限，并记得将小红书使用的这份多维表格 **添加该应用为协作者**。

2. **建立飞书字段：**
   - 在目标表格中，你需要创建以下标准字段（**必须一模一样**）：
     - `博主` (文本/多选)
     - `笔记链接` (超链接)
     - `标题` (文本)
     - `文案` (多行文本)
     - `封面` (附件)
     - `视频/图片` (附件)

3. **保存配置并运行：**
   - 随便打开一个小红书笔记 (`xiaohongshu.com/explore/...`)，点击右上角的浏览器插件图标。
   - 按提示输入所有的密钥信息及飞书表格链接，点击保存并验证。 
   - 接着只需轻点 **“收藏当前笔记”**（或者直接点击页面里注入的红色悬浮球），1-2秒内数据就会悄步出现在你的飞书中！

## ⚠️ 注意事项

- 本项目的数据提取强依赖小红书的前端页面结构，如果官方更改了 `window.__INITIAL_STATE__` 等规则，可能需要重新适配提取逻辑。
- 视频因为体积原因，上传到飞书的时间受你自己的网络带宽影响，较长的视频可能会出现超时（等待即可）。
- 此版本作为效率开源组件仅供学习交流使用。
