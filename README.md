# XHS 一键收藏到飞书 Chrome 插件

这个仓库现在包含一个“仅自己使用”的免外部服务版本：

- `chrome-extension/`：Chrome 插件本体
- `background.js`：直接调用飞书 OpenAPI
- `content.js`：从当前小红书页面提取笔记信息
- `local_bridge.py`：旧版本地桥接服务，现已不是必需

## 工作方式

1. 你在插件设置里填写 `FEISHU_APP_ID`、`FEISHU_APP_SECRET` 和目标飞书表链接。
2. 插件把这些配置保存到 `chrome.storage.local`。
3. 打开一篇小红书笔记后，插件从页面中提取标题、文案、作者、封面、图片或视频链接。
4. 后台脚本直接请求飞书 OpenAPI，创建或更新对应记录。

## 适用范围

这个版本适合：

- 只在你自己的电脑上使用
- 不公开发布
- 接受把飞书密钥保存在本地浏览器扩展存储里

不建议用于：

- 公共发布
- 多人共享安装
- 正式产品化

## 加载 Chrome 插件

1. 打开 Chrome。
2. 进入 `chrome://extensions/`
3. 打开“开发者模式”
4. 点击“加载已解压的扩展程序”
5. 选择目录：`E:\Code-Project\Own-Assistant\chrome-extension`

## 首次配置

在插件里填写：

- `FEISHU_APP_ID`
- `FEISHU_APP_SECRET`
- 飞书多维表 URL
- 是否上传封面/图片附件
- 是否上传视频附件

建议：

- 用一个专门给这个插件准备的飞书应用
- 只授予最小必要权限
- 只让该应用协作你要写入的那张表

## 使用方式

1. 打开一篇小红书笔记页
2. 点击插件图标，先点“保存配置”
3. 点“验证飞书”，确认表格字段可用
4. 点“收藏当前笔记”
5. 或者直接点击页面右下角悬浮“收藏到飞书”按钮

## 飞书表字段要求

当前默认写入这些字段，字段名必须完全一致：

- `博主`
- `笔记链接`
- `标题`
- `文案`
- `视频/图片`
- `封面`

其中：

- `笔记链接` 使用飞书链接字段
- `封面` 尝试上传封面图
- `视频/图片` 对图文笔记上传图片，对视频笔记按你的配置决定是否上传视频

## 当前特性

- 不再需要手动启动本地 Python 服务
- 配置保存在 `chrome.storage.local`
- 支持小红书页面内悬浮收藏按钮
- 同一笔记会按 `note_id` 尝试更新已有记录，而不是重复新增
- 收藏前会校验飞书表是否存在必需字段

## 当前限制

- 页面数据提取依赖小红书当前页面结构，未来页面结构变化时可能需要调整
- 视频附件上传可能更慢，也更容易受源文件大小影响
- 目前没有做密钥加密，只是本地保存
- 旧的 `local_bridge.py` 和 `xhs_batch_to_feishu.py` 仍保留在仓库里，但现在不是必需路径
